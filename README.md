# 🌙 Unsaid

> A safe space to express the thoughts you never say out loud.

Unsaid is a modern anonymous journaling and emotional support web application where users can share feelings without revealing their identity. The goal is to create a calm, minimal, and comforting space for emotional expression.

---

## ✨ Features

- 📝 Create anonymous posts
- 🌙 Clean and minimal dark UI
- 💜 Responsive design
- ⚡ Built with React + Vite
- 🎨 Styled using Tailwind CSS
- 💾 Local storage support (coming soon)
- 😊 Emoji reactions (coming soon)
- 🔍 Category filters (coming soon)

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/athirapsaseendran/unsaid.git
```

Move into the project

```bash
cd unsaid/client
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser at:

```
http://localhost:5173
```
